# MoodNote 팀 과제 비교표 (회의용 v2)

- 비교 대상: HW(문서진) 과제 / SW(이진우) 과제 / 유정 소구점 md(10/10)
- 표기: (확인) 출처 있음, (경험) 개인 경험 n=1, (추정) 검증 전, (미측정) 우리가 측정한 값 아님
- 이 문서는 판단 초안이다. 결정은 회의에서 한다.

## 2. 한눈에 보는 정리

- **두 사람이 같은 말을 한 것**: A(순간 캡처), B(방해 없음), D(프라이버시). 합의가 쉽다.
- **충돌하는 것**: D의 SD 원본 보관 vs 전사 후 삭제, G의 위치 방식. H의 가방 속 한계는 휴대용으로 정리됐다.
- **한쪽에만 있는 것**: C 감정 구조화(SW), E 애착(HW), I 추가 기능(SW).
- **둘 다 비어 있는 것**: Plaud와 비교한 "왜 우리 기기냐", 시작 시간 측정 데이터, 사용자 인터뷰.

## 3. 소구점 구조 (유정 확인 반영)

- **순간 캡처 (기기가 필요한 이유)**: 위 A + B 보조 + 물리 버튼
- **분석 (앱)**: 위 C. 쌓인 기록을 정리해 패턴을 보여준다
- **보조**: 프라이버시(D). 외부 API 사용이 가능하므로 "외부 전송 없음"이 아니라 동의 기반 전송과 삭제 가능으로 표현
- **위로**: 슬픈 기록에는 위로로 반응한다. 상담·진단·치료는 하지 않는다
- 보류: E 애착(가설), F 진화형 AI(로드맵)

## 4. 회의에서 직접 물어볼 질문

1. SD에 쌓이는 원본 음성은 업로드 후 지우는가? 기기를 잃어버리면 파일이 그대로 읽히는가?
2. 외부 API를 쓰기로 하면 어떤 서비스를 쓰고, 음성 원본과 전사본은 어디까지 보내는가? (동의 문구에 반영)
3. 이번 보드에 진동·마이크 스위치를 넣을 것인가? 디스플레이는 LCD인가 E-ink인가?
4. 12/21 학기 종료 기준 발주 마감은 언제인가? (제작·배송 2~3주 + 조립·펌웨어 3~4주는 추정, 업체 확인 필요)
5. 일정이 밀리면 어디서 줄일 것인가? (예: 11/16까지 PCB가 입고되지 않으면 개발보드로 시연)
