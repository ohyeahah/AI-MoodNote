# 연구 활용 동의 기능 – 배포 가이드

## 무엇이 바뀌나요
- 동의 화면에 **[선택] 연구 활용** 칸이 생겨요. 체크하지 않아도 모든 기능을 쓸 수 있어요.
- 연구 활용에 동의한 사람에게만, 일기마다 **"이 일기를 연구에 써도 돼요"** 칸이 보여요. 기본은 꺼짐이에요.
- 설정에서 연구 활용을 끄거나 켤 수 있고, 켠 사람은 **"새 일기의 기본 선택"** 을 한 번 정해 둘 수 있어요.
- 연구에 쓰이려면 **계정 동의 + 그 일기의 체크, 둘 다** 필요해요.
- 동의를 끄면 그 사람의 모든 일기가 즉시 연구에서 빠지고, 다시 동의해도 자동으로 되돌리지 않아요.
- 기존 일기는 모두 "연구에 쓰지 않음"으로 시작해요.

## 배포 순서 (서버에서)
1. Mac에서 commit → push
2. 서버: `bash ~/MoodNote/software/deploy/setup_server.sh update`
3. 서버: `sudo mysql moodnote < ~/MoodNote/software/backend/migrate_v1_7.sql`  (두 번 실행해도 안전해요)
4. 서버: `sudo systemctl restart moodnote`

주의: 2번 후 3번을 하기 전까지 짧게 "서버 오류"가 날 수 있어요. 2→3→4를 이어서 해 주세요.
(이전 v1.6 마이그레이션 `migrate_v1_6.sql`을 아직 안 했다면 그것을 먼저 실행해 주세요.)

## 아직 만들지 않은 것
연구용 내보내기 도구(동의한 사람 + 체크한 일기만, 이름·아이디 제거, 무작위 번호로 바꿔서 추출)는 다음 단계예요.

## 정직하게 알아둘 점
- 서버 운영자는 암호화 키를 갖고 있어서, "체크 안 한 일기는 비밀"은 기술적으로 불가능한 게 아니라 **규칙과 접근 통제**로 지키는 약속이에요.
- AI 감정 추천은 일기를 외부 AI로 보내므로 연구 동의와 별개의 동의예요.
- 실제 연구에 쓰기 전에 학교 연구윤리(IRB) 검토를 받는 걸 권해요. (법률 자문은 아니에요.)
